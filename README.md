# 大富翁抽籤・命運加強版

適合課堂使用的大富翁棋盤抽籤工具，支援多班學生名單、GIF 頭像、教師審批，以及每班持續累計的抽籤統計。

## 立即使用

- **[抽籤前台](https://yuenhk.github.io/Monopoly_Fate10/)**：毋須登入，選擇班別後即可擲骰子或快速抽籤。
- **[教師管理後台](https://monopoly-fate-classroom.onrender.com/admin.html)**：登入後管理班別、名單、統計、頭像、主題影音及機會／命運。
- **學生頭像提交**：使用教師提供的個人連結，不需要教師密碼。

前台公開顯示使用中班別的學生姓名、班號及已批准頭像；任何訪客均可抽籤，結果會加入該班統計。修改名單、查看完整統計、產生提交連結及審批頭像仍只限教師。

## 功能

- 全部在用學生都有機會抽中，沒有排除名單；支援擲骰子及快速抽籤。
- 電腦、iPad 及手機均保留環形大富翁棋盤；抽中學生時顯示大型頭像及主題特效。
- 每班沿用一份持續記錄，無需另外建立課堂。
- Excel 批量匯入／匯出名單：`GROUP` 是系統班別，`CLASS + NO + 中文姓名` 是學生顯示 ID。
- 系統匯出檔附隱藏學生識別欄；保留此欄重新匯入，可改名、改學號及調班，同時保留身份、頭像及歷史記錄。
- 每位學生獨立頭像連結，7 天到期；支援 GIF 動畫、PNG、JPEG、WebP，最多 5 MB。教師批准後才公開顯示。
- 班別統計支援累積、每月及每週，以圖表、學生名單及抽籤明細呈現，可匯出 CSV；日期以香港時間計算。
- 後台可編輯機會及命運內容，每項以分號及空行分隔。
- 在主題設定逐項試播影音，取消允許即可全站禁播；只使用已列明來源及授權的片庫，網上搜尋不會自動加入播放。
- 各後台分頁顯示資料／待處理數量；頭像審批為 0 時顯示綠色，有待審批時顯示黃色。
- 班別名單上方可直接匯出全班頭像提交連結 CSV，包含學生顯示 ID 及 7 天有效期；重新產生會停用舊連結。

新班別（包括 Excel 匯入新增班別）預設「每人等機率」；既有班別保留原有骰子走格模式，可在後台「班別與名單 → 抽籤方式」切換。等機率模式從所有可選格子均勻抽取，學生各佔一格，因此每位在用學生有相同機會；機會／命運仍保留，事件後下一抽會從全班學生中均勻抽取。棋盤只展示動畫，不用骰子點數決定結果。原有骰子模式仍從目前位置向前走，每位學生每次機率未必相同。兩種模式都允許同學再次中籤，沒有永久排除學生。伺服器保存結果，同一請求重試不重複記錄。

## 三款主題

在教師後台「主題設定」透過卡片內的實景動態預覽選擇、試聽及預覽，再按「儲存主題」套用。可選「全站預設」或個別班別；班別可指定主題或沿用全站預設。設定跨裝置保存；不會改動學生自訂頭像或抽籤記錄。已開啟的前台在下次操作、返回頁面或約 30 秒內取得新設定。

| 主題 | 配色 | 音樂與抽籤音效 | 抽中學生特效 | 背景循環影片 |
| --- | --- | --- | --- | --- |
| 迷因（預設） | 沿用原有配色 | 原有 MEME 音樂、memes.tw 全庫按名稱篩選 | 原有彩炮 | 使用者提供的授權 Rick Roll 原版 MV，完整循環背景 |
| 貓 | 奶油橘 | 喵聲編排的節奏音樂、喵聲音效 | 噴出多款貓咪 | 已審核溫馨小貓片，4選3輪播 |
| 狗 | 暖棕 | 汪聲編排的節奏音樂、汪聲音效 | 噴出多款狗狗 | 已審核溫馨小狗片，4選3輪播 |

卡片實景預覽沿用真正前台 HTML／CSS，顯示示範學生頭像及靜音背景循環影片；只有目前選中的卡片會播放，其餘卡片暫停；不讀取真實名單、不呼叫 API、不產生抽籤紀錄，離開主題分頁時停止播放。

影片保留在主頁背景靜音循環，沒有新增中央影片區，棋盤佈局、字體和字級沿用原有設定。音效開關同時控制背景音樂及抽籤音效；瀏覽器須有使用者操作才可播放有聲音訊。減少動態效果設定會停用背景影片及噴發動畫。全站影音禁播設定持續保留，切換主題不會重新啟用。

主題 ID 經伺服器驗證，只有教師可以修改；公開前台只讀取選定主題。音樂、影片隨專案提供，正常運行不需要額外的影音 API 或服務。可在後台查看[素材來源及授權](theme-media/credits.html)；貓狗影片、採樣及其音樂改編依 CC BY-SA 3.0 提供，與其他原有素材的授權分開處理。

素材產生腳本 `scripts/build-theme-media.py` 只用於維護素材，需要 numpy、Pillow、imageio-ffmpeg（或 `FFMPEG_BIN`），及一款可顯示中文的字型；非 macOS 可用 `CJK_FONT` 指定字型。輸入來源放在 `.archive/theme-sources/`，公開檔案位於 `theme-media/`，全部來源、作者及修改說明見上述授權頁。

| 每班獨立主題 | 「班別與名單」或「主題設定 → 套用範圍」設定。可沿用全站預設，或為該班指定迷因、貓、狗主題。 |
| 獨立音量 | 前台「聲音與顯示」分別控制背景音樂和抽籤音效，0 即關閉；原有總音效開關保留。設定存在該網址的本機瀏覽器，不屬跨裝置備份內容。 |
| 完整備份與還原 | 後台「備份與還原」匯出 `.json.gz`，包含全部班別（含封存）、學生（含停用）、GIF 頭像、抽籤紀錄及取消計數狀態、學生連結、事件、音效勾選及主題設定。不含教師密碼、鹽值或登入狀態。 |
| 投影與低耗能 | 前台「聲音與顯示」啟用投影可收起工具列，按 Esc 或「離開投影」返回；低耗能停用背景影片、略過走格動畫並減少粒子。任何尺寸均保留棋盤。 |

還原流程：上載本系統完整備份 → 查看目前與還原後的數量、增刪改筆數及差異範例 → 下載現況備份 → 確認檔案已保存 → 輸入「取代全部資料」才套用。預覽 10 分鐘到期；期間資料有變動會拒絕套用，須重新預覽及備份。資料庫交易確保失敗時整份回復。還原不改教師密碼，原學生連結按備份的 token 雜湊及有效期恢復，其他時期產生的連結則不再有效。

備份是 gzip 壓縮，**沒有加密**，包含學生資料，請保存在私人位置。頭像合共最多 60 MB、解壓後備份最多 100 MB；檔案內容、圖片格式、關聯識別、設定及網址會先驗證，不能從備份匯入密碼或執行程式碼。還原是整份取代，不能與現有名單合併；只修正名單時請用 Excel 匯入。

## 架構

| 平台 | 用途 |
| --- | --- |
| GitHub | 原始碼、專案介紹及更新歷史 |
| GitHub Actions | 自動測試、建置及發佈 Pages |
| GitHub Pages | 完整抽籤前台，毋須先登入或經入口頁跳轉 |
| Render | 公開抽籤 API、教師登入與管理後台、學生頭像提交 |
| Neon PostgreSQL | 跨裝置保存名單、抽籤明細、設定及頭像 |

GitHub Pages 只託管靜態 HTML、CSS 及 JavaScript，不能獨自運行登入、資料庫或上載服務。前台從 Pages 呼叫 Render 的公開抽籤 API；教師後台及學生提交頁保留在 Render 同一網域，以免依賴跨網站登入 Cookie。[GitHub Pages 官方說明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)

`/api/play/` 只提供使用中班別、棋盤資料、已選音效及抽籤，不使用教師登入 Cookie。完整統計、名單編輯、Excel 匯出入、學生提交連結及頭像審批等管理 API 繼續要求教師登入。未審批頭像只限教師讀取，學生個人 token 不能操作管理功能。

## 本機運行

需要 Node.js 24 或以上：

```sh
npm ci
npm start
```

首次運行後，從終端取得設定代碼，在 `http://localhost:3000/admin.html` 建立教師密碼（至少 12 字元）。設定好班別及學生後，前台 `http://localhost:3000/` 毋須登入即可抽籤。教師登入有效 12 小時。

本機資料保存於 `data/monopoly.sqlite`，包含頭像；測試使用獨立暫存資料庫。需要同一 Wi-Fi 手機試用時，使用 `HOST=0.0.0.0 npm start`，並以電腦的區域網絡 IP 開啟；學生不能使用另一部電腦的 localhost 連結。

## Excel 更新流程

1. 上載含 `GROUP | CLASS | NO | 中文姓名` 四個欄位的 `.xlsx`，先預覽，再確認套用。
2. 小規模修改時，先從後台匯出，修改可見欄位並保留隱藏學生識別欄，再重新匯入。
3. 預設「新增及更新」保留檔案外學生；「同步涉及班別」只移出檔案中出現的 GROUP 內未列出的學生，其他班別不受影響。

檔案最多 5 MB、5,000 位學生，每班最多 100 人；學號須為 1–9999 整數。初次匯入以 GROUP＋CLASS＋NO 配對，重複上載不會新增副本。歷史統計歸屬抽籤當時的班別。封存班別或移出學生不會刪除過往記錄。

## 部署及更新

Render 使用 Node Web Service（Free），新加坡區域，建置 `npm ci --omit=dev`、啟動 `npm start`、健康檢查 `/healthz`。資料及頭像保存在 Neon；沒有 `DATABASE_URL` 時 Render 會拒絕啟動，避免把正式資料寫入暫存 SQLite。

| 設定 | 值／用途 |
| --- | --- |
| Render `DATABASE_URL` | Neon 的秘密 PostgreSQL 連線字串，保留 TLS 參數；不可放入 GitHub 或前端 |
| Render `NODE_VERSION` | `24` |
| Render `HOST` | `0.0.0.0` |
| Render `COOKIE_SECURE` | `true` |
| Render `NODE_ENV` | `production` |
| Render `PUBLIC_APP_ORIGIN` | `https://yuenhk.github.io`；自訂網域時填對應的 HTTPS origin，不含路徑 |
| GitHub Actions repository variable `RENDER_APP_URL` | `https://monopoly-fate-classroom.onrender.com` |

GitHub Settings → Pages 的 Source 選 **GitHub Actions**。後端更新後先在 Render 手動部署最新 commit，確認 API 正常，再執行 **Publish classroom entry on GitHub Pages** 工作流程。現有 Render 服務使用公開 Git 程式庫的 `deploy/classroom-v2.4.3` 分支；更新時須同步該分支及 main。

`scripts/build-pages.mjs` 只把棋盤 HTML、前端程式、公開設定及視聽素材寫入 `pages-dist/`。不發佈管理頁、學生提交頁、後端原始碼、資料庫或密碼；`play-config.js` 只包含公開 Render 網址。不要把 `data/`、`.archive/`、`node_modules/` 或 `.env` 上載到 GitHub。

Render 免費服務閒置會休眠，首次開啟可能需等待喚醒。資料及頭像在 Neon，部署重啟後仍會保留。參考：[Render 免費服務](https://render.com/docs/free)、[Neon 連線設定](https://neon.com/docs/connect/connect-from-any-app)。

## 搞笑音效與教師禁播

迷因主題恢復 memes.tw 完整原庫（隨附 1,135 段清單），以 sound-title-policy.js 統一篩除名稱含粗口、成人、不雅、暴力驚嚇或爆音字眼的項目；前台、後台清單及模擬使用同一篩選。既有教師禁播及舊音效停用設定繼續生效。貓狗叫聲維持原有設定。名稱不能證明實際音訊內容，並非逐段人工聽審；外站音效可能失效。

在「主題設定」選主題後，可逐項預覽音效、4段影片（包含後備）及音樂，查看對白、來源與授權。取消「允許全站播放」即持續全站禁播，直到教師重新啟用。每週影片清單及後備均須經禁播篩選；讀不到禁播設定時暫停影音，棋盤仍可使用。新開頁／下次操作會取得設定，已開啟頁面約30秒內同步。升級前已開啟的舊版前台請重新整理一次。

「開啟模擬抽獎」提供可操作棋盤、骰子、搞笑／主題音效、示範中籤頭像及主題特效；只用合成示範學生，沒有任何抽籤寫入API。禁播也適用於模擬。已禁播項目仍可由教師手動試播檢查。禁播設定留存在資料庫，不因還原較舊學生備份而解除。

貓狗音效及內附舊素材的來源記錄見 `theme-media/school-sounds.json` 和 `theme-media/credits.html`。memes.tw 音效直接使用來源站連結，權利歸原作者，沒有另行宣稱取得授權。

三款主題各有 3 條已核對來源授權的短片，靜音隨機輪播；每輪播放完 3 條才重新洗牌，避免前後兩輪接連播放同一條。直向片使用模糊側邊填滿橫向畫面，保留主角。既有半透明棋盤、文字保護底色、音樂及抽籤特效維持原設定。失效素材會跳過，整組無法播放時使用原有內附影片作後備；低耗能／減少動態效果及非使用中後台卡片會暫停。

### 每週自動輪替（現行政策）

GitHub Actions每週一香港時間06:15只從已核對的本地片庫選片，各主題4選3。教師電腦不需開機，排程可能延遲；可手動執行Refresh weekly classroom background videos。搜尋只產生候選資料，不直接下載或核准新片。迷因片庫混合真人趣片與課堂反應動畫，貓狗片庫溫馨可愛。

Pages與Render共同讀取公開影片清單，沒有教師憑證；前台再套用Render保存的全站禁播設定。即使被禁播素材仍在某次週更清單或後備設定內，也不會自動播放。檔案指紋或片庫檢查失敗時停止發布。執行離線輪替不需要ffmpeg：`python3 scripts/refresh-background-library.py`。

### v2.6.3 前台臨時選擇主題

毋須登入，可在前台頂部「主題」選迷因／貓／狗，同時改變本頁配色、音樂、抽籤特效及影片。只在目前頁面有效：不寫入 localStorage、sessionStorage 或教師設定，同頁切換班別仍保留所選主題；重新整理／重開後恢復班別設定。選單只顯示迷因、貓、狗三款；選單預設收起。背景自動同步及抽籤不會覆蓋本頁選擇，亦不影響其他裝置。
